# Role
你是一名精通 Java Spring Boot, MyBatis 和前端可视化的全栈开发专家。
我正在开发 "Memory-Assistant" 记忆卡片项目。

# Context (背景)
项目数据库中已经积累了用户的复习记录 (`review_log`)。
现在的 `dashboard.jsp` 比较单调，我希望引入 **ECharts** 图表库，展示用户 **“近 7 天的学习情况”**。

# Database Schema (Reference)
参考已有的 `review_log` 表结构：
- `review_date` (复习时间)
- `is_correct` (1=记得, 0=忘了)
- `user_id` (用户ID)

# Requirements (需求详情)
请帮我实现以下全栈功能：

1.  **后端 - 数据统计 (Mapper & XML)**:
    -   修改 `ReviewLogMapper`。
    -   新增方法 `selectDailyStats(Long userId, LocalDate startDate, LocalDate endDate)`。
    -   **SQL 逻辑**: 按日期分组 (`GROUP BY DATE(review_date)`)，统计每天的：
        -   `review_count` (总复习次数)
        -   `correct_count` (正确次数，即 sum(is_correct))
    -   **注意**: 只需要查询数据库中存在的数据，日期的补全逻辑放在 Java 层处理。

2.  **后端 - 业务逻辑 (Service)**:
    -   新建或修改 `ReviewService.java`。
    -   实现 `getLast7DaysStats(Long userId)` 方法。
    -   **核心逻辑 (Data Filling)**:
        -   获取当前日期 `LocalDate.now()`。
        -   循环生成过去 7 天的每一天（例如：从 Today-6 到 Today）。
        -   将数据库查到的数据填充进去。**关键点**：如果某天没有复习记录，该天的数量和正确率必须默认为 0，不能在图表上缺省。
        -   返回一个 Map 或 DTO，包含两个数组：`dates` (日期列表), `counts` (复习数量列表), `rates` (正确率列表)。

3.  **后端 - 接口 (Controller)**:
    -   在 `CardController` (或新建 `StatsController`) 中添加 GET 接口 `/api/stats/weekly`。
    -   返回 JSON 数据供前端 AJAX 调用。

4.  **前端 - 可视化 (`dashboard.jsp`)**:
    -   引入 ECharts CDN 链接。
    -   在页面显眼位置（例如顶部或侧边栏旁）增加一个 `div` 容器用于渲染图表。
    -   编写 JavaScript 代码：
        -   页面加载完成后，请求 `/api/stats/weekly`。
        -   使用 ECharts 渲染一个 **“折线柱状混合图” (Line + Bar)**。
        -   **X轴**: 日期 (MM-dd)。
        -   **Y轴(左)**: 复习数量 (柱状图)。
        -   **Y轴(右)**: 正确率 (折线图，0-100%)。
        -   样式要求：简洁美观，颜色符合 Bootstrap 风格。

# Tech Constraints

           create table flashcard_deck

               id          bigint auto_increment comment '卡组ID'

               id               bigint auto_increment comment '卡片ID'

               deck_id          bigint                                  not null comment '所属卡组ID',

               wrong_count      int           default 0                 null comment '错误次数',
               difficulty       decimal(3, 2) default 1.00              null comment '难度系数: 0.50-2.00',
               create_time      datetime      default CURRENT_TIMESTAMP null comment '创建时间',
               update_time      datetime      default CURRENT_TIMESTAMP null on update CURRENT_TIMESTAMP comment '更新时间',
               status           tinyint       default 1                 null comment '状态: 0-归档, 1-学习中, 2-已掌握',

                   foreign key (deck_id) references flashcard_deck (id)

           )
