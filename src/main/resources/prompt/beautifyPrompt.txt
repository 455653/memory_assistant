# Role
你是一名具有极高审美水平的高级前端工程师和 UI/UX 设计师。
我有一个基于 Java Spring Boot + JSP + Bootstrap 5 的 Web 项目 "Memory-X"。
目前后端功能已完善，但界面非常简陋（像学生作业）。
**我需要你帮我重写 JSP 页面的前端代码，进行彻底的美化。**

# Strict Constraints (严格约束 - 非常重要！)
1.  **禁止修改任何后端逻辑**：绝对不要改动 `<c:forEach>`, `<c:if>`, `${variable}`, `<form action="...">`, `name="..."`, `id="..."` 等逻辑代码。
2.  **保留所有功能**：确保所有的按钮点击事件、表单提交、AJAX 调用依然能正常工作。
3.  **技术栈**：继续使用 Bootstrap 5，但必须配合**自定义 CSS** 来打破“默认感”。
4.  **图标库**：请引入并使用 **Bootstrap Icons** (CDN) 来丰富界面。

# Design System (设计规范)
请基于以下风格进行设计：
* **字体**：使用 'Inter' 或 'Noto Sans SC'，显得现代、清爽。
* **配色**：
    * 主色 (Primary): `#4e73df` (科技蓝)
    * 背景 (Background): `#f8f9fc` (极淡灰)
    * 卡片 (Card): 白色 + 柔和的阴影 (`box-shadow: 0 0.15rem 1.75rem 0 rgba(58, 59, 69, 0.15)`)
* **质感**：在导航栏或登录框使用**玻璃拟态 (Glassmorphism)** 效果 (半透明模糊)。
* **圆角**：使用较大的圆角 (e.g., `border-radius: 15px`)。

# Tasks (具体任务)

请为我生成以下 4 个文件的完整代码（包含 CSS 样式）：

## 1. 全局样式与登录页 (`login.jsp`)
* **背景**：使用一张高质量的唯美图片（可用 Unsplash URL），覆盖全屏。
* **登录框**：居中显示的白色半透明卡片（玻璃拟态），加深阴影。
* **输入框**：移除默认边框，改为底部边框或柔和的灰色填充。
* **按钮**：全宽的大圆角渐变按钮。

## 2. 仪表盘首页 (`dashboard.jsp`)
* **顶部欢迎区**：设计一个 Banner 区域，显示“欢迎回来, ${user.username}”。
* **数据统计卡片**：将“待复习”、“总卡片”等做成醒目的数据看板。
    * 左侧显示数字和标题，右侧显示一个浅色的大图标（如透明度 20% 的大图标）。
* **图表容器**：美化 ECharts 的容器边框和标题。

## 3. 卡组详情页 (`deck-detail.jsp`)
* **列表美化**：
    * 不要用传统的 Table 表格。
    * 将每一张卡片 (`flashcard`) 设计成一个独立的**长条形悬浮卡片**。
    * 鼠标悬停 (`hover`) 时，卡片轻微上浮并加深阴影。
    * “问题”文本加粗，“答案”文本用灰色显示。
    * 状态标签（如“阶段 3”）使用圆角 Badge，颜色要柔和。

## 4. 沉浸式复习页 (`review.jsp`)
* 这是最核心的页面，需要极简、专注。
* **卡片容器**：页面中央放置一个巨大的、类似纸质质感的卡片容器。
    * 正面/背面文字要大，排版精美。
* **翻转效果**：点击“查看答案”时，尝试实现淡入淡出或 CSS 翻转效果。
* **反馈按钮组**：
    * [🔴忘了] [🟡模糊] [🟢记得]
    * 按钮要大，带有明确的图标，且颜色区分明显。

# Output Requirement
请直接提供修改后的**完整 JSP 代码**。
对于 CSS，你可以选择直接写在 JSP 的 `<style>` 标签中（为了方便我复制），或者提取为一段通用的 `<style>` 放在 `<head>` 里。
