# Role
你是一名精通 Java Spring Boot 3.x, MyBatis, JSP 以及大模型应用开发的架构师。
我正在开发 "Memory-X" 记忆卡片项目。
我现在需要实现一个核心功能：**“基于 AI 的文档自动制卡” (AI Flashcard Generation)**。

# Context (项目背景)
1.  **现有技术栈**: Spring Boot + MyBatis + MySQL + JSP + Bootstrap 5。
2.  **现有表结构**: `flashcard_deck` (卡组), `flashcard` (卡片)。
3.  **API 服务**: 我将使用 **DeepSeek API** (`deepseek-chat` 模型)。虽然官方示例是 Node.js，但我需要你用 **Java** 实现调用。
    -   Base URL: `https://api.deepseek.com`
    -   DeepSeek API 兼容 OpenAI SDK 格式。


# Requirements (需求详情)
请帮我实现“用户上传 Word/PDF -> AI 分析生成问答对 -> 用户预览并勾选 -> 保存入库”的完整流程。

## 1. 依赖管理 (pom.xml)
请提供处理文件上传和解析文档所需的 Maven 依赖：
-   **Apache PDFBox**: 用于解析 `.pdf` 文件。
-   **Apache POI**: 用于解析 `.docx` Word 文件。
-   **OkHttp3** 或 **Hutool-http**: 用于发送 HTTP 请求调用 DeepSeek API。
-   **Jackson**: 用于解析 AI 返回的 JSON 数据。

## 2. 后端 - 文档解析服务 (`DocumentParserService`)
请创建一个服务类，包含以下功能：
-   `String parsePdf(MultipartFile file)`: 提取 PDF 纯文本。
-   `String parseDocx(MultipartFile file)`: 提取 Word 纯文本。
-   **文本清洗与分片 (Critical)**:
    -   由于 API Token 限制，文档可能太长。请实现一个 `cleanAndChunk(String text)` 方法。
    -   **策略**: 将提取的文本按 **2000字符** 为单位进行切分，目前仅取**前 2 个切片**（或前 5000 字）发送给 AI，避免 Token 溢出（请在注释中说明这一点，方便我后续扩展）。

## 3. 后端 - AI 交互服务 (`DeepSeekAIService`)
请实现调用 DeepSeek API 的逻辑：
-   **Prompt 设计 (核心)**:
    -   System Prompt: "你是一个专业的助教。请根据用户提供的文本，提取关键知识点，生成 5-10 个 '问题' 和 '答案' 对。必须严格返回 JSON 格式，数组结构，无需 Markdown 标记。格式示例: `[{\"question\":\"...\", \"answer\":\"...\"}]`"
-   **API 调用**:
    -   使用 Java 代码构建 POST 请求。
    -   Header: `Authorization: Bearer {your_api_key}`
    -   Model: `deepseek-chat`
    -   解析 API 返回的 JSON 字符串，映射为 `List<GeneratedCardDTO>`。

## 4. 后端 - 控制器 (`AiDeckController`)
你需要处理两个阶段的请求：
-   **阶段一：上传与预览**
    -   `POST /deck/ai/preview`: 接收 `file` 和 `deckName`(可选)。
    -   调用解析服务 -> 调用 AI 服务。
    -   将生成的 `List<GeneratedCardDTO>` 存入 `HttpSession` (避免重复调用 AI)，并跳转到 `ai_preview.jsp`。
-   **阶段二：保存选择**
    -   `POST /deck/ai/save`: 接收用户在前端勾选的卡片索引（或重新提交完整的卡片列表）以及最终的 `deckName`。
    -   创建新的 `FlashcardDeck` (User ID 从 Session 获取)。
    -   批量插入 `Flashcard` 到数据库。
    -   清除 Session 中的临时数据，重定向到卡组列表。

## 5. 前端 - 交互页面 (`ai_create.jsp` & `ai_preview.jsp`)
-   **ai_create.jsp**: 简单的文件上传表单 (`multipart/form-data`)。
-   **ai_preview.jsp**:
    -   显示生成的卡片列表（左边问题，右边答案）。
    -   每行前面有一个 **Checkbox**，默认全选。
    -   底部输入框允许用户修改“卡组名称”。
    -   “确认导入”按钮提交表单。

# Technical Constraints (技术约束)
1.  **API Key 配置**: 请将 API Key 放在 `application.properties` 中 (`deepseek.api.key=...`)，并在 Service 中通过 `@Value` 读取。
2.  **JSON 处理**: AI 返回的内容可能包含 Markdown 代码块标记（如 ```json ... ```），请编写简单的正则或字符串处理逻辑去除这些标记，确保 `ObjectMapper` 能解析。
3.  **异常处理**: 如果文件解析失败或 API 调用超时，请返回友好的错误提示。
